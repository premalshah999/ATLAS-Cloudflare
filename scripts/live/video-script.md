# ATLAS demo — scene script (motion video, premium voice)

Each scene: kicker · title · narration. Screens are captured live from the installed app on the operator profile.

1. (title card) Cloudflare Git challenge · **An automated team of software engineers**
   "This is ATLAS: a team of AI software engineers that plans, builds, reviews, verifies and ships real software — with a person deciding what lands."
2. Dashboard · **Real work on a real product**
   "Here it is working on Operon, a complaint-operations platform with a FastAPI backend and a React dashboard. Every number on this screen is live."
3. Planning · **The orchestrator staffs the mission**
   "You describe an outcome. The orchestrator model — DeepSeek, through the official API — proposes a plan: tasks, dependencies, and the right specialists. Nothing runs until you approve it."
4. Mission Control · **Agents in parallel, each in its own worktree**
   "Coders, testers, a reviewer, a security engineer and browser QA work at the same time, each in an isolated git worktree inside the operating-system sandbox."
5. Agent detail · **Direct any agent, mid-flight**
   "Open any agent to see its decisions and every tool call. The composer sends a direction straight into its live session; it keeps its context."
6. Review · **Findings on the diff**
   "The reviewer and the security engineer pin findings to the exact lines. Real ones from this run: an unbounded export, a missing role check."
7. Deployments · **The deployment cycle**
   "ATLAS verifies independently: tests, API checks, browser flows, then a staging deploy whose served revision it reads back, with synthetic traffic."
8. Honest gate · **An agent's word is never evidence**
   "When a check fails — here, console errors from the app's own security policy — the mission is marked failed, not verified. The team fixes it and runs again."
9. GitHub · **Accept, push, pull request, CI**
   "Accepted changes are pushed and opened as pull requests on GitHub, where CI runs. A failing CI can start a follow-up mission automatically."
10. Cloudflare · **Every checkpoint on Cloudflare Artifacts**
   "Completed missions are published to a per-mission Cloudflare Artifacts repository through our Worker, which reads every commit back before ATLAS records it."
11. (title card) **Engineering, under command.**
   "ATLAS. Many agents, one repository, real evidence — and you in command."
